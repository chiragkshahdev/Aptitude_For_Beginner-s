# Day 01 - Number System - Zero to Hero

### 🎯 Aaj Kya Sikhoge?
Aptitude ka base yahi hai. Agar ye samajh gaya toh 50% quant easy lagega.

### 1. Numbers ke Types
- **Natural:** 1, 2, 3... (Counting)
- **Whole:** 0, 1, 2, 3...
- **Integer:**...-2, -1, 0, 1, 2...
- **Prime:** Sirf 2 se divide - 2, 3, 5, 7, 11, 13... (2 sabse chota prime hai, aur akela even prime)
- **Composite:** Prime nahi hai - 4, 6, 8, 9...
- **Co-Prime:** Dono ka HCF 1 ho - ex: (3, 5)

### 2. Divisibility Rules - Interview me sabse zyada pucha jata hai
| Number | Rule |
|--------|------|
| 2 | Last digit even (0,2,4,6,8) |
| 3 | Sab digits ka sum /3 se divide ho |
| 4 | Last 2 digits /4 se divide ho |
| 5 | Last digit 0 ya 5 |
| 6 | 2 aur 3 dono se divide ho |
| 9 | Sab digits ka sum /9 se divide ho |
| 11 | (Even place ka sum - Odd place ka sum) = 0 ya 11 |

### 3. Unit Digit Trick
2 ka power cycle 4 ka hai: 2, 4, 8, 6 repeat.
Example: 2^100 ka unit digit? 100/4 = remainder 0 -> 6 hoga.

### 4. Formulas Yaad Karo
- 1+2+3+...+n = n(n+1)/2
- 1^2+2^2+...+n^2 = n(n+1)(2n+1)/6
