# Day 003 - Simplification &BODMAS - Formulas

### BODMAS Rule Order
**B** - Brackets '() {} []'
**O** - Of / Order (Power, Square Root)
**D** - Division
**M** - Multiplication
**A** - Addition
**S** - Subtraction

### VBODMAS Extension
V - Vinculum (Bar) -
B - Brackets
O - Of
D - Division
M - Multiplication
A - Addition
S - Substraction

### Important Formulas
1. a<sup>2</sup> - b<sup>2</sup> = (a+b)(a-b)
2. (a+b)<sup>2</sup> = a<sup>2</sup> + b<sup>2</sup> + 2ab
3. (a-b)<sup>2</sup> = a<sup>2</sup> + b<sup>2</sup> - 2ab
4. (a+b)<sup>3</sup> = a<sup>3</sup> + b<sup>3</sup> + 3ab(a+b)
5. (a-b)<sup>3</sup> = a<sup>3</sup> - b<sup>3</sup> - 3ab(a-b)
6. a<sup>3</sup> + b<sup>3</sup> = (a+b)(a<sup>2</sup> - ab + b<sup>2</sup>)
7. a<sup>3</sup> - b<sup>3</sup> = (a-b)(a<sup>2</sup> + ab + b<sup>2</sup>)
